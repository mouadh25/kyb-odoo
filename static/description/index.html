KYB — Algerian Corporate Identity & Temporal Fiscal Compliance

Real-time NIF/RC auto-completion (<10ms), CNRC status verification, and temporal VAT deductibility audit (CIDTA Art. 176 & CTCA Art. 30) for Odoo 16, 17, 18, 19, and 20.

⚡ Pre-Indexed Sovereign Cache Latency: p50 < 8ms · p95 < 15ms

⚡ Instant NIF & RC Auto-Completion

Entering a 15-digit NIF or RC in res.partner auto-populates Raison Sociale, registered address, NIS, and Article d'Imposition in under 10ms.

🛡️ Temporal Fiscal Compliance Audit

Audits vendor status on the exact invoice issuance date under CIDTA Art. 176, protecting your deductions against retrospective deregistration reassessments.

🔍 Fuzzy Name Search Autocomplete

Type company names in partner dropdowns across sales, purchases, and invoices to instantly select verified Algerian corporations.

🇩🇿 100% Sovereign Data Residency

Compliant with Law 18-07 / 25-11. All data is processed directly inside Algeria at the Algérie Télécom Cloud Datacenter in Algiers.

Quick Configuration (2 Minutes)

1 Install the module: Click Install in the Odoo Apps menu or clone from GitHub.
2 Configure System Parameters: In Settings → Technical → Parameters → System Parameters, set kyb.api_key to your API key (or test with sk_test_kyb_sandbox_key_001).
3 Verify Partners: Open any partner form, enter a NIF, and click "Vérifier Fiche KYB".
